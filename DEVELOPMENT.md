# Development guide

How to build, test, translate and release Gordeck.

## Building the Flatpak

Requirements: `flatpak`, [Flatpak Builder](https://flathub.org/apps/org.flatpak.Builder) and the KDE SDK.

```bash
flatpak install --user flathub org.kde.Sdk//5.15-25.08 org.kde.Platform//5.15-25.08 org.flatpak.Builder
```

Build and install:

```bash
flatpak run org.flatpak.Builder --user --install --force-clean build-dir flatpak-build.yaml
flatpak run com.bnx.gordeck
```

## Building natively

The `.github/scripts/build-native.sh` script installs the dependencies, builds, runs the unit tests and produces the `.deb`/`.rpm` package on Ubuntu, Debian, Fedora and Arch Linux. To use it without touching your system, run it inside a container:

```bash
podman run --rm -v "$PWD":/src:ro,Z -w /src -e BUILD_DIR=/tmp/build -e DIST_DIR=/tmp/dist \
	docker.io/library/ubuntu:24.04 bash .github/scripts/build-native.sh
```

Swap the image for `debian:12`, `registry.fedoraproject.org/fedora:41` or `archlinux:latest` for the other distributions.

## Installer and Steam integration

| File | Purpose |
|---|---|
| `installer/install.sh` | Graphical installer (zenity) for the Steam Deck |
| `installer/add-to-steam.py` | Adds Gordeck to Steam as a non-Steam game, with artwork |
| `installer/steam-art/` | Steam covers, banner, logo and icon; generated by `generate.py` |
| `installer/build-package.sh` | Builds the Flatpak and produces `dist/Gordeck-Instalador.tar.gz` |

`add-to-steam.py` modifies Steam's `shortcuts.vdf`, so Steam must be closed. Useful options: `--dry-run`, `--remove`, `--remove-legacy` (removes Chiaki4deck shortcuts) and `--steam-dir` (to test against a copy of the Steam folder).

## Translations

The interface strings live in `gui/i18n/` and are embedded into the executable at build time. After changing strings in the code, update the translation file and fill in the new entries:

```bash
cd gui
lupdate -no-obsolete -locations none src include -ts i18n/chiaki_pt_BR.ts
```

## Continuous integration and releases

The `.github/workflows/build.yml` workflow runs on every push and pull request:

- builds and runs the tests on Ubuntu 24.04, Debian 12, Fedora 41 and Arch Linux;
- produces the `.deb` and `.rpm` packages, `gordeck.flatpak` and `Gordeck-Instalador.tar.gz`.

To publish a release, push a tag; the workflow creates the release with all the files:

```bash
git tag v2.1.1
git push origin v2.1.1
```

The version is set in `CMakeLists.txt` (`CHIAKI_VERSION_MAJOR`, `MINOR` and `PATCH`).
